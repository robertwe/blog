CentOS6 "host" and "dig" commands are missing

2014-05-20

Recently I configured a new machine with CentOS 6.5 on board and it turned out the host command was missing. Here is a quick solution for that: yum install bind-utils

Just to keep it in one place - I always forget which package provides it. If you know where exactly the executable file is placed, you can use the yum provides command like this:
